# About this starter

This repository is a Northwestern University Libraries-branded starting point for Canopy IIIF projects. It configures collections, manifests, and theming the same way as the default Canopy template — this variant simply layers on Northwestern branding conventions so you can copy/paste the working pieces into your own project.

## Colophon

Canopy is an open-source project of [Northwestern University Libraries](https://www.library.northwestern.edu/), where it supports digital scholarship in many forms. This starter's demo content is drawn from Northwestern University Libraries' [Digital Collections](https://dc.library.northwestern.edu/).

## Next steps

- Point `canopy.yml` at your own collection and manifests.
- Review `DESIGN.md` in this repository for the current state of Northwestern-specific layout, theme, and styling decisions.
