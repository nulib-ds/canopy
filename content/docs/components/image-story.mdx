# ImageStory

`<ImageStory>` wraps [Storiiies](https://www.cogapp.com/r-d/storiiies) by [Cogapp](https://www.cogapp.com/), an open-source tool for guiding users through a sequence of annotations on an image. `<ImageStory>` accepts IIIF Manifest URIs with annotations targeting rectangles or points on images, and renders them as a guided tour with built-in navigation and annotation text.

This tour uses *An Indian woman burning herself on the death of her husband* from the British India
art demo. It draws its image from Northwestern University Libraries'
[source Manifest](https://api.dc.library.northwestern.edu/api/v2/works/009e37b7-5c36-4451-bafb-f1217f45877f?as=iiif).
The [Storiiies Manifest](https://manifest.storiiies-editor.cogapp.com/v3/c083t) adds an authored tour;
its annotations are separate from the provider's catalog record.

<ImageStory
  iiifContent="https://manifest.storiiies-editor.cogapp.com/v3/c083t"
  height="900"
/>

```mdx
<ImageStory
  iiifContent="https://manifest.storiiies-editor.cogapp.com/v3/c083t"
  height="900"
/>
```

## Authoring with Storiiies Editor

Use the [Storiiies Editor](https://editor.storiiies.cogapp.com/) to write a tour and choose the image
regions it describes. Pass the resulting Manifest URL to `<ImageStory>` to embed it in MDX.

### Determine Manifest URL

1. Click **Links** in the editor and copy the bookmark URL.
2. Find the tour identifier in that URL. This example uses `c083t`.
3. Use the identifier at the end of the Manifest URL:
   `https://manifest.storiiies-editor.cogapp.com/v3/c083t`.

## API

| Prop                | Type           | Required | Notes                                                                        |
| ------------------- | -------------- | -------- | ---------------------------------------------------------------------------- |
| `iiifContent`       | string         | ✅       | Storiiies manifest URL. Relative paths are prefixed with the site base path. |
| `disablePanAndZoom` | boolean        |          | Disables mouse navigation when `true`.                                       |
| `height`            | string\|number |          | CSS height for the container. Defaults to `600`.                             |
| `className`         | string         |          | Adds classes to the wrapper div.                                             |
