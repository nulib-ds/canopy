# Scroll

`<Scroll>` displays a Manifest's text annotations beside its images in a vertical reader. It supports
multiple languages and the formats `text/plain`, `text/html`, and `text/markdown`. Annotation pages
can be embedded in the Manifest or linked from it.

This example uses *A collection of original drawings to illustrate the costume and manners of the
Hindoos* from the British India art demo. The Manifest links a text AnnotationPage from the Canvas
labeled “page 1 verso.” The reader displays the supplied text; it does not create a transcription.

```mdx
<Scroll iiifContent="https://api.dc.library.northwestern.edu/api/v2/works/1b5b4a4e-af4e-4fe0-9984-a3f8284d53a2?as=iiif" />
```
